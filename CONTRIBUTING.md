# Contributing

This repository is a collection of solved LeetCode problems.

## Adding a solution

- Keep one problem per directory using the existing numeric problem naming convention.
- Include the problem's solution in the language already used for that directory when practical.
- Prefer clear, interview-ready implementations over unnecessary abstraction.
- Do not commit generated IDE files, local environments, or credentials.

## Verification

Run the relevant solution locally against representative examples and edge cases before committing.
